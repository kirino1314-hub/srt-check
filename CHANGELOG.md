# Changelog

## 0.1.0 — Initial trial

- Read-only SRT validation with text and JSON reports.
- Format, timing, overlap, reading-speed, line-count and estimated CJK-width checks.
- New-report-only output protection and configurable thresholds.
- Windows demo launcher; standard-library regression and launcher tests.
- Traditional Chinese and English guides, synthetic examples and feedback templates.

Pre-release testing corrected large-duration overflow, sub-millisecond boundary comparison, and Windows interpreter-probe fallback. These corrections are part of the initial trial, not separate historical releases.
